# Sistema de Chamados de TI

## Sobre o projeto

Sistema desenvolvido para auxiliar no registro,
organização e acompanhamento de chamados de suporte
técnico em pequenas empresas.

## Problema

Solicitações de suporte realizadas de maneira informal
podem ser esquecidas, dificultando o acompanhamento dos
atendimentos e a identificação das demandas prioritárias.

## Solução

O sistema permite registrar chamados, definir prioridades,
acompanhar o status dos atendimentos e consultar o histórico
das solicitações.

## Funcionalidades

- Cadastro de usuários
- Abertura de chamados
- Definição de prioridade
- Listagem de chamados
- Alteração de status
- Busca de chamados
- Exclusão de chamados
- Relatórios

O projeto será desenvolvido inicialmente em Java,
com evolução planejada para uma aplicação web utilizando
Spring Boot e banco de dados MySQL.
